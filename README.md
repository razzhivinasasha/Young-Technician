## :rocket: О проекте

**«Юный техник»** — это современный интернет-магазин с большим выбором смартфонов, планшетов и ноутбуков по доступным ценам. Проект разработан с акцентом на семантическую верстку, поисковую оптимизацию и идеальное отображение на любых типах устройств.

## :hammer_and_wrench: Стек технологий и инструменты:

*   **HTML5** — семантическая разметка.
*   **CSS3** — современные методы раскладки и стилизации:
    *   **Flexbox** — для линейных компонентов (навигационное меню, карточки, элементы выравнивания).
    *   **CSS Grid** — для построения сложных сеток основных секций.
    *   **Шрифты** — подключение сторонних шрифтов для соответствия дизайн-макету.
*  **@media** — Сайт автоматически подстраивает внешний вид страницы под размер экрана (телефон, планшет или компьютер).
**Методология БЭМ** (Блок-Элемент-Модификатор) для чистоты и масштабируемости кода.

## :card_index_dividers: Структура проекта:

*   `index.html` — главная страница лендинга.
*   `index.css/` — папка со стилями проекта.
*   `img/` — графические ресурсы и изображения товаров.
*   `README.md` —  описание проекта.
*   `main.js ` — файл скриптов (добавлен на перспективу для реализации интерактивных элементов).

Проект оптимизирован под следующие диапазоны устройств:

*   **Десктопная версия** - ПК и ноутбуки
*   **Мобильная версия** - Для вертикальной `(max-width: 479.98px)` и для горизонтальной ориентации (`(min-width: 480px) and (max-width: 931.98px)`)
*   **Планшеты** - (`(min-width: 932px) and (max-width: 1279.98px)`)

Применяется подход гибкой верстки, чтобы все элементы масштабировались плавно и пропорционально.

## :brain: Практический опыт и ключевые навыки

1. **SEO и социальные теги:**
   * Внедрены базовые метатеги `keywords` и `description` для улучшения видимости в поисковых системах.
   * Настроены протоколы **Open Graph** (`og:title`, `og:description`, `og:type`) для красивого отображения карточки сайта при репостах в социальных сетях.
2. **Интеграция интерактивных карт:**
   * В секцию контактов встроена интерактивная Яндекс.Карта через элемент `iframe`.
   * Карта полностью адаптирована под ширину экрана (`width="100%"`), а также добавлен обязательный атрибут `title` для обеспечения доступности (Accessibility).
3. **Глубокая адаптивность:**
   * Проработана сетка для различных разрешений экрана.
   * На смартфонах и в горизонтальной ориентации реализовано скрытое/компактное меню.
   * Для экономии места на экранах до 932px длинный логотип заменяется на лаконичные инициалы **«ЮТ»**, а элементы навигации аккуратно раздвигаются по краям с помощью `justify-content`.

При работе над адаптивным дизайном возникла проблема: на экранах от 480px до 931.98px форма обратной связи (`<form>`) ломала разметку и выходила за пределы области видимости экрана, создавая нежелательную горизонтальную прокрутку.

**Решение:**
Причиной был некорректный размер контейнера формы. Проблема была устранена путем пересчета внутренних отступов (`padding`), ограничения максимальной ширины блока до `700px` и автоматического выравнивания по центру. 

**Код Desktop**
```Css
/* Обратная связь */
form {
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    border: 1px solid rgba(118, 118, 118, 0.5);
    border-radius: 50px;
    width: 700px;
    height: auto;
    margin: 45px auto 96px;
    padding: 27px 60px 47px 55px;
    gap: 26px;
}
input,
textarea {
    width: 100%;
    border: 1px solid rgba(118, 118, 118, 0.5);
    border-radius: 50px;
    font-weight: 300;
    font-size: 28px;
    color: #696969; 
    padding: 12px 0 12px 30px;
}
textarea {
    padding-left: 23px;
    margin-bottom: 21px;
}
```
**Код исправления для @media():**

```css
@media screen and (min-width: 480px) and (max-width: 931.98px) {
    /* Обратная связь */
    .form {
        padding: 0 30px;
    }
    form {
        width: 100%;
        max-width: 700px;
        height: auto;
        margin: 40px auto;
        padding: 30px 30px;
        gap: 20px;
        border-radius: 20px;
    }
    input,
    textarea {
        border-radius: 10px;
        font-size: 3vw;
        padding: 10px;
    }
    form button {
        width: 40%;
    }
}
```
